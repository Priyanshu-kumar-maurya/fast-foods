## 🌟 Key Features

- 🍕 **Interactive Food Menu:** Dynamic filter tabs for Burgers, Pizzas, Appetizers, Drinks, and Desserts.
- 🔍 **Real-Time Live Search:** Instant dish search filtering by name and ingredients.
- 🛒 **Full Shopping Cart System:**
  - Slide-out Cart Drawer with LocalStorage persistence.
  - Increment / Decrement quantity with instant subtotal and tax calculation.
  - Promo code discounts (e.g. `TASTY20` for 20% OFF).
  - Dynamic free shipping calculation over $30.
- 🎉 **Order Confirmation Modal:** Instant order placement animation with generated Order ID and receipt summary.
- 📱 **100% Responsive Design:** Smooth scrolling and adaptive layout tailored for mobile devices, tablets, and 4K desktops.
- ⚡ **Zero Bulky Frameworks:** Pure Vanilla JavaScript, HTML5, and CSS3 for ultra-fast load times.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Priyanshu-kumar-maurya/fast-foods.git
cd fast-foods
```

### 2. Run locally
Simply open `index.html` in your web browser:
```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```
